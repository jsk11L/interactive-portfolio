# Artwork

`frontend/public/images/artwork/daydream-candle.webp` was created with the built-in ImageGen tool for this portfolio. No existing album art was supplied or edited. A CSS flame and glow animate above the wick; reduced motion and the pause control stop the animation.

Final prompt:

> Use case: stylized-concept. Asset type: square editorial album artwork for a personal developer portfolio inspired by the contemplative mood of Daydream Nation. Create an ORIGINAL photograph-like painterly study of a single tall warm ivory wax candle, unlit with a tiny dark wick, centered horizontally, rising from the bottom crop, against a plain muted charcoal olive-gray studio background. Candle top / wick at exactly 40 percent image height and 50 percent width; candle body slender, about 13 percent of image width. Subtle analogue film grain, soft imperfect focus, subdued atmospheric lighting, timeless 1980s art-book scan, quiet and very restrained. Square crop. No fire or flame (a live animated flame will be added in code), no text, no letters, no logo, no border, no hands, no props. Do not copy an existing painting; original lighting and wax texture.

The Dearly shoreline is an original SVG in `DearlyHero.vue`. The Judge Bot cover is an original vector illustration in `public/images/projects/judge-bot-cover.svg`. Existing project PNGs and the supplied profile photograph were preserved; WebP derivatives are used in the website. Project covers are presented as conceptual artwork, not product screenshots.
