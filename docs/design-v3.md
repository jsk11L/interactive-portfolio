All ten keep the same verified profile, projects and experience. Floating language selection is always available, with English as the initial language and explicit choices remembered. Reduced motion and pause controls suppress decorative animation. The plan deliberately replaces the repeated generic section stack and two default catalog treatments; shared data and accessible controls remain common.
